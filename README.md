# PostgreSQL Vetorizado com pgvector

Este projeto disponibiliza uma infraestrutura Plug & Play de banco vetorial utilizando PostgreSQL + pgvector via Docker Compose.

O objetivo é permitir que qualquer aplicação de IA com RAG (Retrieval-Augmented Generation) consiga armazenar embeddings e realizar buscas semânticas rapidamente.

---

## Tecnologias Utilizadas

- PostgreSQL 16
- pgvector
- Docker
- Docker Compose

---

## Como subir a infraestrutura

Execute o comando abaixo:

```bash
docker-compose up -d
